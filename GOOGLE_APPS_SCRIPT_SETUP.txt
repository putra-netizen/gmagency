GOOGLE APPS SCRIPT SETUP - GM AGENCY

1. Buka Spreadsheet -> Extensions -> Apps Script.
2. Hapus Code.gs lama.
3. Paste isi file Code.gs dari folder ini.
4. Isi:
   SPREADSHEET_ID = ID spreadsheet kamu
   SHARED_SECRET = secret yang sama dengan Vercel
5. Deploy -> New deployment -> Web app.
   Execute as: Me
   Who has access: Anyone
6. Copy URL /exec.
7. Vercel Environment Variables:
   GOOGLE_SHEETS_WEBHOOK_URL = URL /exec
   SHEETS_WEBHOOK_SECRET = secret yang sama
8. Buat trigger:
   Function: onEditInstallable
   Event source: From spreadsheet
   Event type: On edit

PENTING:
- Sheet harus bernama persis: Web_Orders, Shopee_Orders, Review_Orders
- Script otomatis menambahkan kolom row_id dan updated_at jika belum ada.
- Jangan pakai URL /dev. Pakai URL deployment /exec.
